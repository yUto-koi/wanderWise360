# WanderWise 360

**WanderWise 360** is a first-year group project for the University of Computer Studies, Yangon (UCSY). It is a front-end travel discovery website that introduces visitors to destinations across Myanmar and presents sample travel packages.

**Live website:** [wanderWise 360](https://wanderwise360.vercel.app/)

## Project overview

The website is designed to help visitors discover places to visit in Myanmar. The homepage brings together popular destinations and browsable collections of regions and states, pagodas, hills, and beaches. Visitors can open destination pages for brief attraction information and images, and browse example travel packages with listed prices in Myanmar kyat (MMK).

## Key features

- Homepage featuring popular destinations and travel categories.
- Destination browsing by Myanmar region and state.
- Destination detail pages with attraction highlights and photographs.
- Search field and region/state selector in the site navigation.
- Travel package listings spanning beach getaways, cultural trips, and adventure tours.
- Navigation to the Home, Services, Packages, and About pages.

## Technology

- **HTML** for page structure
- **CSS** for layout and visual presentation
- **JavaScript** for client-side behavior

## Run locally

The site is deployed at the live website linked above. To preview a local copy, place the project files in a folder, start a static web server from that folder, and open the local address in a browser. For example, with Python installed:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000). The project's main page is `index.html`.
